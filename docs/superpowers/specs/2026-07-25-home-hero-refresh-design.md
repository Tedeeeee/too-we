# 홈 상단 히어로 개편 디자인

## 목표

제공된 새 레퍼런스를 기존 402×874 모바일 홈 화면에 비례 환산해 적용한다. 홈의 데이터 흐름, 월별 기록 목록, 하단 내비게이션은 유지하고 상단 헤더와 대기 중 기록 캐러셀만 재구성한다.

## 접근 방식

검토한 방식은 다음 세 가지다.

1. 새 데스크톱 전용 레이아웃을 추가하는 방식
2. 기존 홈 카드만 확대하는 방식
3. 레퍼런스를 402px 모바일 캔버스에 비례 환산하는 방식

현재 프로젝트가 고정 402px 모바일 캔버스를 기준으로 모든 화면을 구성하고 있으므로 세 번째 방식을 사용한다. 별도 반응형 분기를 추가하지 않아 화면 전환과 하단 내비게이션의 기존 동작을 보존할 수 있고, 레퍼런스의 카드 노출 비율도 재현할 수 있다.

## 헤더

- 장미 로고와 `오늘,우리는` 제목을 화면 상단으로 이동한다.
- 다른 주요 화면과 같은 상단 리듬을 위해 헤더와 이어지는 콘텐츠 전체에 16px 여유를 추가한다.
- 기존 로고와 제목 크기는 유지해 자산의 선명도를 보존한다.
- 겹친 두 프로필을 상단 우측으로 함께 이동한다.
- 제목 아래의 `우리가 머문 자리에 꽃갈피를 남겨주세요` 문구는 제거한다.
- 프로필 이니셜과 클릭 동작은 기존 데이터 및 마이페이지 이동을 유지한다.

## 대기 기록 캐러셀

- 캐러셀은 화면 상단 80px에서 시작한다.
- 첫 카드 아이템은 좌측 24px, 348×228px로 배치한다.
- 카드 간격은 12px으로 두어 다음 카드의 종이 가장자리가 약 20px 보이게 한다.
- `note2-2.svg`는 382×242px로 사용하고 아이템 내부에서 좌측 -17px, 상단 -8px, 가로 배율 1.22로 배치해 종이의 실제 외곽이 카드 영역을 채우도록 한다.
- 스크롤 인덱스 계산은 새 카드 간격인 360px을 사용한다.

## 카드 내용

- 날짜 스티커 SVG의 바탕을 빨강에서 연분홍으로 변경하고 실제 기록 날짜를 `YY.MM.DD 기록` 형식으로 겹쳐 표시한다.
- 장소명, 안내 문구, 빈 꽃갈피 SVG는 기존 동적 데이터와 자산을 유지하며 새 카드 위치에 맞춘다.
- CTA 문구는 `한 줄 남기기`에서 `꽃갈피를 남겨주세요`로 변경한다.
- CTA는 높이를 줄이고 필기체와 더 큰 연필 SVG를 사용한다.
- 기존 `짝궁이 당신의 답을 기다리고 있어요!` 보조 문구는 새 레퍼런스에 없으므로 카드에서 제거한다.

## 하단 연결

- 캐러셀 점은 카드 아래로 이동한다.
- 월별 기록 스크롤 영역은 도트 아래 336px에서 시작하며 화면 하단 위치는 그대로 유지한다.
- 월별 기록 카드, 데이터 그룹화, 기록 상세 이동, 하단 내비게이션은 변경하지 않는다.

## 검증

- 홈 전용 소스 계약에서 제거된 안내 문구, 새 CTA, 카드 크기·간격·SVG 좌표를 검사한다.
- SVG 자산, UI SVG 및 화면별 SVG 사용 검증을 모두 실행한다.
- 프로덕션 빌드를 실행한다.
- Orca 실화면에서 헤더 위치, 첫 카드 폭, 다음 카드 노출, CTA, 하단 목록 연결을 확인한다.
