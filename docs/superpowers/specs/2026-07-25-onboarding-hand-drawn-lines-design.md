# 온보딩 손그림 구분선 디자인

## 목표

온보딩의 이름 입력, 초대 코드 입력, 초대 코드 공유 화면에서 기계적인 직선과 점선을 제거하고 사용자가 선택한 “자연스러운 굴곡”의 손그림 SVG 선으로 통일한다.

## 시각 방향

- 첨부 이미지처럼 선의 높낮이가 작고 불규칙하게 변한다.
- 굴곡은 글자보다 먼저 눈에 띄지 않을 정도로 잔잔하게 유지한다.
- 애니메이션이나 무작위 변형은 사용하지 않아 화면을 다시 열어도 동일한 모양을 보인다.
- 선 끝은 둥글게 처리한다.

## 자산

`design-assets/svg/onboarding/`에 다음 원본을 추가한다.

- `line-long.svg`: 이름 입력과 공유 카드에 사용하는 가로 358 기준의 긴 선
- `line-short.svg`: 초대 코드의 각 입력 칸에 사용하는 짧은 선

두 SVG는 투명한 캔버스에 단일 path만 포함하며, 자산 레지스트리의 `onboardingSvg`와 `svgSize`에 등록한다.

## 컴포넌트

`HandDrawnLine` 컴포넌트를 추가한다.

- `variant`: `long` 또는 `short`
- `color`: 상태별 선 색
- `width`, `height`: 배치 크기
- 외부 SVG를 CSS mask로 사용해 같은 원본을 여러 색으로 표현한다.
- 장식 요소이므로 접근성 트리에서는 숨긴다.

## 화면별 적용

### 이름 입력

- 기존 358×2 회전 직선을 제거한다.
- 같은 좌우 경계와 중심 높이를 유지하는 358×12 손그림 선을 배치한다.
- 입력 텍스트와 글자 수 표시 위치는 유지한다.

### 초대 코드 입력

- 기존 `SEG_ROTS`와 회전된 직선 6개를 제거한다.
- 각 flex 칸에 짧은 손그림 선을 배치한다.
- 입력 완료 칸과 현재 입력 칸은 진한 색, 나머지는 옅은 베이지를 사용한다.
- 현재 입력 칸은 색과 선 굵기로만 구분하고 위치는 흔들지 않는다.

### 초대 코드 공유

- 기존 dashed border를 제거한다.
- 안내 문구와 코드 사이의 동일한 위치에 옅은 긴 손그림 선을 배치한다.
- 카드, 코드, 버튼의 위치와 동작은 유지한다.

## 검증

- SVG 자산 레지스트리와 화면 사용 계약을 자동 검사한다.
- 기존 직선, `SEG_ROTS`, dashed border가 제거되었는지 확인한다.
- `npm run svg:verify-usage`, `npm run svg:verify`, `npm run build`를 실행한다.
- 402×874 브라우저 화면에서 이름, 코드, 공유 화면을 각각 캡처해 굴곡과 정렬을 확인한다.
