# 지도 화면 SVG 정리 디자인

## 목표

지도 화면의 시간 칩과 하단 장소 선택 패널을 프로젝트의 기존 SVG 시각 언어로 통일한다.

## 자산 재사용

- 시간 칩은 등록된 `uiSvg.time`을 사용한다.
- 장소 행 구분선은 기존 `HandDrawnLine`의 `long` 변형을 사용한다.
- 새 SVG 파일이나 지도 전용 복제 자산은 만들지 않는다.

## 시간 칩

- 기존 `◷` 텍스트 글리프를 제거한다.
- `uiSvg.time`을 16×16 이미지로 렌더링한다.
- SVG 원본의 짙은 색을 현재 보조 텍스트 톤에 맞추기 위해 이미지에 낮은 불투명도를 적용한다.
- 칩의 패딩, 간격, 텍스트 말줄임, 위치는 유지한다.

## 하단 장소 패널

- 세 장소 행 아래의 1px 직선 구분선을 제거한다.
- 각 위치에 `HandDrawnLine`을 `width=362`, `height=12`, `color=palette.beige`로 렌더링한다.
- 손그림 선의 중심이 기존 직선의 y좌표와 같도록 `기존 top - 6px`에 배치한다.
- 장소 텍스트와 전체 행 클릭 영역은 변경하지 않는다.

## 접근성

- 시간 아이콘은 텍스트와 함께 있는 장식 이미지이므로 빈 `alt`를 사용한다.
- `HandDrawnLine`은 기존처럼 접근성 트리에서 숨긴다.

## 검증

- `MapSelect.jsx`에서 `uiSvg.time`과 `HandDrawnLine`을 사용하는지 검사한다.
- 기존 `◷` 글리프와 1px 직선 구분선이 제거됐는지 검사한다.
- 402×874 지도 화면에서 시간 칩 두 개와 하단 구분선 세 개를 확인한다.
- SVG 사용 검사, SVG 파일 검사, 프로덕션 빌드를 실행한다.
