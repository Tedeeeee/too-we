# 마이페이지 레퍼런스 정합 디자인

## 목표

현재 마이페이지를 제공된 모바일 레퍼런스와 같은 시각적 위계로 정리한다. 기존 데이터와 수정 시트 동작은 유지하고, 화면의 배치와 SVG 사용 방식만 다듬는다.

## 핵심 결정

- 프로필 영역의 큰 카드와 그림자를 제거한다.
- 두 프로필은 글자나 테두리 없이 파란색 유기형 도형으로 표시한다.
- 두 프로필 사이에는 배경이 없는 채워진 하트 SVG를 사용한다.
- 함께한 기간 문구는 가운데 정렬하고 `+N` 부분만 올리브색으로 강조한다.
- 설정 제목과 두 설정 행은 레퍼런스의 세로 위치와 폭에 맞춰 독립 배치한다.
- 연결 해제는 카드가 아닌 흐린 우측 정렬 텍스트 버튼으로 표시한다.
- 화면 아래에는 모바일 홈 인디케이터를 표시한다.

## 레이아웃

기준 뷰포트는 프로젝트의 모바일 폭인 402px이다.

- 헤더: 상단 뒤로가기와 화면 중앙 제목을 서로 독립 배치한다.
- 프로필: 상단 약 112px에 96px 크기의 도형 두 개를 가운데 배치한다.
- 함께한 기간: 상단 약 229px, 전체 폭 중앙 정렬.
- 내 정보 수정: 상단 약 262px, 가운데 정렬.
- 설정 제목: 좌측 4px, 상단 약 337px.
- 설정 행: 좌측 2px, 폭 398px, 높이 56px. 첫 행 363px, 둘째 행 428px.
- 연결 해제: 우측 16px, 상단 약 516px.
- 홈 인디케이터: 화면 하단에서 4px 위, 중앙 정렬.

## 데이터와 동작

- 사용자 이름, 상대방 이름, 함께한 기간, 설정 값은 기존 상태를 그대로 사용한다.
- 내 정보 수정 버튼과 설정 행의 기존 클릭 동작을 유지한다.
- 연결 해제 동작은 이번 시각 수정 범위에서 변경하지 않는다.
- 작은 화면에서도 가로 스크롤이 생기지 않도록 폭을 뷰포트 안으로 제한한다.

## SVG

기존 `heart.svg`는 흰 배경 사각형을 포함하므로 마스크 아이콘으로 사용할 때 사각형 전체가 칠해진다. 다른 화면에 영향을 주지 않도록 원본은 유지하고, 배경이 없는 `heartFilled.svg`를 별도로 등록해 마이페이지에서만 사용한다.
