# 오늘,우리는 MVP 기능 명세 스냅샷

> 원본 기획: https://app.notion.com/p/3aacea2af9f4801c8c8ced6463fed68d
> 스냅샷 기준: 2026-07-29
> 이 문서는 에이전트 작업용 요약이다. 정책 변경은 Notion에서 먼저 승인한 뒤 이 파일에 반영한다.

## 제품 정의

두 사람이 함께 방문한 장소에 각자의 짧은 한 줄을 남기고, 그 기록을 지도와 월별 기록으로 다시 꺼내 보는 커플 데이트 추억 서비스다.

- 추천 서비스가 아니라 기록·공유 서비스다.
- 기록 생성의 시작점은 홈의 `+` 버튼과 장소 검색이다.
- 방문 기록은 한 줄, 사진, 별점, 태그, 꽃갈피가 없어도 저장된다.
- 연결된 두 사람만 공동 기록을 볼 수 있다.
- 현재 React 화면은 시각 기준이며 이 문서는 동작 기준이다.

## MVP 범위

- 익명 사용자와 온보딩
- 이름 입력
- 초대 코드 생성·입력·공유
- 최대 두 명의 커플 연결
- 홈 대기 카드와 월별 기록
- Kakao 장소 검색과 지도
- 빈 방문 기록 생성
- 각 사용자의 한 줄과 별점
- 기록 상세와 수정
- 사진 최대 5장
- 선택형 꽃갈피와 태그
- 가고 싶은 곳
- 마이페이지
- 연결 해제와 데이터 삭제
- 모바일 웹/PWA 기본 대응
- 로딩, 빈 화면, 오류, 재시도 상태

## MVP 제외

- 데이트 장소·코스 추천
- 공개 피드, 채팅, 미션, 결제
- 복수 커플 연결
- 다른 기기·계정 복구
- 카카오 로그인
- 푸시 알림
- 개인 보관함
- 꽃갈피 통계와 고급 필터

## 인증과 연결

- MVP는 로그인 화면 없이 익명 세션으로 시작한다.
- 익명 사용자는 기기·브라우저에 귀속된다.
- 브라우저 데이터 삭제나 기기 변경 시 복구할 수 없음을 안내한다.
- 한 사용자는 하나의 활성 커플에만 속한다.
- 한 커플에는 최대 두 명이 연결된다.
- 한 커플에는 한 번에 하나의 활성 초대 코드만 둔다.
- 코드는 연결 성공 후 재사용할 수 없다.
- 잘못된 코드, 사용 완료 코드, 정원이 찬 코드를 구분한다.
- 연결 요청은 중복 전송돼도 한 번만 반영한다.
- 반복 코드 시도를 제한한다.
- 2차 단계에서 기존 익명 사용자에 카카오 로그인 수단을 연결한다.

## 방문 기록과 사용자 상태

방문 기록은 장소와 방문 시점에 대한 공동 데이터다. 사용자별 한 줄과 별점은 개인 기록으로 분리한다.

- 장소, 날짜, 시간은 필수다.
- 사진, 태그, 꽃갈피, 한 줄, 별점은 선택이다.
- 같은 장소의 다른 날짜 방문을 별도 기록으로 저장할 수 있다.
- 개인 기록은 방문 기록과 사용자 조합당 최대 하나다.
- 상대방의 한 줄과 별점은 볼 수 있지만 수정할 수 없다.

유효한 한 줄은 앞뒤 공백을 제거한 뒤 한 글자 이상인 텍스트다.

- 현재 사용자의 유효한 한 줄이 없으면 대기 카드에 표시한다.
- 현재 사용자의 유효한 한 줄이 있으면 월별 기록에 표시한다.
- 별점, 사진, 태그, 꽃갈피만 있어도 한 줄이 없으면 대기 상태다.
- 상대방의 작성 여부는 현재 사용자의 대기 여부를 바꾸지 않는다.
- 작성한 한 줄을 비우면 해당 사용자에게 다시 대기 카드가 나타난다.

상태 예시:

1. 두 사람 모두 미작성: 둘 모두 대기
2. A만 작성: A는 월별 기록, B는 대기
3. 둘 모두 작성: 둘 모두 월별 기록

## 꽃갈피

- 방문 기록당 공동 꽃갈피 하나 또는 선택 없음이다.
- 신규 기록은 선택 없음으로 시작한다.
- 수정 화면은 기존 선택을 복원한다.
- 선택한 꽃을 다시 누르면 해제한다.
- 어떤 꽃이든 어떤 기록에 사용할 수 있다.
- 꽃말은 안내 정보이며 기능 제한이나 점수가 아니다.
- 꽃갈피는 대기 상태와 권한에 영향을 주지 않는다.
- 연결된 두 사람 모두 변경하거나 해제할 수 있다.

## 사진

- 방문 기록당 최대 5장이다.
- 두 사람 모두 사진을 추가할 수 있다.
- MVP에서는 자신이 올린 사진만 삭제할 수 있다.
- 업로드 전 모바일 환경에 맞게 압축한다.
- 여러 장 중 일부만 실패하면 실패한 파일만 재시도한다.
- 데이터 삭제 시 원본과 파생 파일을 함께 제거한다.
- 파일당 용량과 허용 형식은 외부 서비스 설정 단계에서 확정한다.

## 지도와 가고 싶은 곳

- 위치 권한을 거부해도 키워드 장소 검색은 가능해야 한다.
- 지도 로딩 실패 시 장소·기록 목록으로 핵심 동작을 이어간다.
- 외부 장소 정보가 바뀌어도 당시 기록을 유지하도록 Kakao 장소 정보를 스냅샷으로 저장한다.
- 가고 싶은 곳은 방문 기록과 별도로 관리한다.
- MVP에서는 가고 싶은 곳을 자동으로 방문 완료 처리하지 않는다.

## 권한과 동시성

- 활성 커플 구성원만 해당 커플의 데이터를 조회·변경할 수 있다.
- 다른 커플의 사용자, 기록, 사진, 가고 싶은 곳에 접근할 수 없다.
- 장소, 날짜·시간, 태그, 꽃갈피는 두 사람 모두 수정할 수 있다.
- 개인 한 줄과 별점은 작성자만 수정·삭제할 수 있다.
- 공동 정보 동시 수정은 MVP에서 마지막 저장값을 적용하고 최신 데이터를 다시 불러온다.
- 기록 생성과 연결 완료 요청은 중복 실행에 안전해야 한다.
- 네트워크 실패 시 화면 입력값을 유지한다.

## 연결 해제와 삭제

- 마이페이지에서 두 번의 명시적 확인을 거친다.
- 해제 성공 즉시 양쪽 사용자의 공동 데이터 접근을 차단한다.
- 다음 진입 시 온보딩으로 돌아간다.
- 개인 보관함과 복구 기능은 제공하지 않는다.
- 데이터와 사진 삭제 요청을 즉시 시작하고 최대 24시간 안에 영구 삭제한다.
- 30일 숨김 보관 정책은 사용하지 않는다.
- 해제 요청 자체가 실패하면 기존 연결과 데이터를 유지한다.
- 삭제 작업 실패는 재시도하고 운영상 추적할 수 있어야 한다.

## 필수 인수 시나리오

1. 서로 다른 두 기기가 초대 코드로 연결된다.
2. 장소만 저장하면 양쪽 모두 대기 카드가 나타난다.
3. A만 한 줄을 작성하면 A는 월별 기록, B는 대기 카드에서 본다.
4. B도 작성하면 양쪽의 대기 카드에서 사라진다.
5. 한 줄을 비우면 해당 사용자에게 다시 대기 카드가 나타난다.
6. 같은 장소의 여러 방문을 별도 기록으로 찾을 수 있다.
7. 꽃갈피를 선택하지 않거나 자유롭게 선택·해제할 수 있다.
8. 꽃갈피 변경은 대기 상태에 영향을 주지 않는다.
9. 사진은 최대 5장이며 일부 실패를 개별 재시도할 수 있다.
10. 위치 권한을 거부해도 장소를 검색하고 기록할 수 있다.
11. 다른 커플의 데이터 식별자를 알아도 접근할 수 없다.
12. 연결 해제 후 접근이 즉시 차단되고 데이터가 최대 24시간 안에 삭제된다.
